STUDENT MANAGEMENT SYSTEM
Project Overview
The Student Management System is a Python-based application developed using SQLite. It helps manage student information and marks through a menu-driven interface.

The system allows administrators to add, view, search, update, and delete student records. It also provides functionality to manage student marks. Students can log in to view their profiles and marks.

Features
1. User Authentication
Student registration
User login
Admin login
Role-based menus
2. Student Management
Add new students
View all students
Search for students
Update student details
Delete student records
3. Marks Management
Add marks for students
View student marks
Update marks
Delete marks
Validate marks between 0 and 100
4. Database Management
SQLite database
Store student details and marks
Connect student records with their marks using student IDs
